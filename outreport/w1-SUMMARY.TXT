VQEAF OS 0.1.0 - rescue volume

This disk is the way in. It is built in RAM: no partition on
the phone has to survive for these bytes to exist, and nothing
on the phone can take them back.

Read it with build/read-report-raw.ps1 (raw sectors, no mount
needed). Write to it by copying files onto the mounted volume
and then FLUSHING it (build/send-cmd.ps1 calls the volume
flush for you): Windows writes the directory entry when it
flushes the FAT, so a copy that has finished in Explorer is
not yet visible to the phone.
Do not eject to flush. Measured on this PC 2026-10-26: an
eject takes the medium away (the disk stays on the bus as
"No Media") and nothing the host can do unelevated brings it
back - only re-plugging the cable, or a reboot of the phone.

  help  status  net  dmesg  ps  ls PATH  cat PATH  mountall
  coldplug  start NAME  stop NAME  mkdir PATH  rm PATH
  sync  screen  reboot  poweroff  recovery  bootloader
  flash recovery FILE confirm     (see HELP.TXT)
Each answer is preceded by '### ' and the line it answers,
so a response of several commands can be read back on a PC.
